## 记录规则

- 只记三类：Issue 合并、方向定案、协作规则变化。
- 每条一句话（约 60 字内），后附 Issue / PR 或 commit 号；同一天同一主题的多个 Issue 可以并成一条。
- 不记：小改动（commit message 就是记录）、复核与审查过程、验证命令与测试数（在 PR 里）、Issue 创建。
- 只记已发生的事实，不写计划。
