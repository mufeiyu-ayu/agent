# Skills

`SkillsService` 管理本人技能的草稿/当前发布指针，`SkillsController` 只开放本人列表、预览、启停、删除和用户确认发布。模型工具在 `tools/skill-tools.ts`，没有发布工具。

- `SkillContent` 在 OSS PUT 前登记；唯一对象名不覆盖，成功事务才将它标记采用并移动草稿指针。错误或取消不会移动已确认指针。发布用预览内容的不可变 ID 做 CAS，旧预览 409；重复确认同一发布结果幂等。
- 发布前读取并校验完整对象；云端对象不是数据库事务的一部分。未绑定的失败上传保留可核查记录。已采用内容为运行与审计保留，不提供用户可见历史版本或回滚。
- 删除是立即撤销后续发现/管理的 tombstone；已有 Run 持有的不可变内容仍可读。内置包由部署提供，个人不能覆盖其名称。
- 每次聊天生成授权快照，显式选择先读取，自动选择经 read_skill。相同 Run 持有同一资源引用；实际正文/参考文件作为工具结果持久化，首次及后续模型采样 input.skills 保存目录与原始指令。
- 沙箱资源只在 bash 前准备到 root 管理的 `/opt/kuro-skills/<fingerprint>/<name>`，不进入用户源码归档。读取文本不创建沙箱。
